¿Cómo funciona el sistema?

PsicoEscuela es una aplicación web de una sola página (SPA) — esto significa que todo está en un solo archivo HTML que cambia dinámicamente según lo que hace el usuario, sin recargar la página.

Flujo general de la aplicación:

1

El usuario abre index.html

El navegador carga el HTML, luego el CSS (estilos) y finalmente el JavaScript (lógica).

2

Verificación de sesión

JavaScript revisa si hay una sesión guardada en localStorage. Si la hay, entra directo al sistema.

3

Login

Si no hay sesión, muestra el formulario de login. El usuario ingresa email/contraseña y JavaScript los verifica contra la base de datos.

4

Carga de datos

Al entrar, JavaScript descarga todos los datos (estudiantes, casos, alertas, etc.) desde la API y los guarda en memoria (STATE).

5

Navegación y módulos

El usuario navega por el sidebar. Cada sección se muestra/oculta con CSS. Los datos se muestran renderizando HTML dinámicamente.

6

CRUD (Crear, Leer, Actualizar, Eliminar)

Cada módulo tiene botones para crear, editar y eliminar registros. Los cambios se envían a la API y se actualizan en pantalla.

HTML index.html — La interfaz

Este archivo contiene toda la estructura visual del sistema. Está dividido en secciones:

Sección 1: Login Page (<section id="login-page">)

Es la pantalla de inicio que ve el usuario antes de entrar. Contiene el logo, formulario de email/contraseña y el botón de ingreso.

<!-- Para cambiar el mensaje de bienvenida, busca esto: -->

<p>Sistema de Gestión Psicológica Estudiantil</p>

Sección 2: App principal (<div id="app">)

Esta sección solo se muestra cuando el usuario está autenticado. Contiene:

  • <aside class="sidebar"> → El menú lateral izquierdo
  • <header class="topbar"> → La barra superior
  • <main class="main-content"> → El contenido de cada página

Sección 3: Páginas internas (<section class="page-section">)

Cada módulo del sistema (estudiantes, casos, citas...) es una sección que se muestra u oculta. Solo una está visible a la vez.

<!-- Para cambiar el título de una sección, busca su id: -->

  ...
</section>

Sección 4: Modales (<div class="modal-backdrop">)

Las ventanas emergentes (formularios de crear/editar) están al final del archivo. Cada modal tiene un id único.

Módulo: Login

El login verifica las credenciales contra la tabla psicologos en la base de datos:

// En js/app.js — busca esta función:
document.getElementById('login-form').addEventListener('submit', async (e) => {
  const email = document.getElementById('login-email').value;
  const pass  = document.getElementById('login-pass').value;

  // Descarga la lista de psicólogos desde la base de datos
  const psicologos = await apiGet('psicologos');

  // Busca si existe un psicólogo con ese email y contraseña
  const user = psicologos.find(p => p.email === email && p.password_hash === pass);

  if (user) {
    // Guarda sesión y entra al sistema
    localStorage.setItem('psico_user', JSON.stringify(user));
    iniciarApp();
  }
});
⚠️ Seguridad: En este sistema demo, la contraseña se guarda en texto plano para simplicidad. En producción real, deberías usar bcrypt o similar para hashear las contraseñas en un backend.

Para agregar un nuevo usuario psicólogo:

Los usuarios se guardan en la tabla psicologos. Puedes agregar uno directamente desde el sistema o modificar los datos iniciales en la función de carga de datos del archivo README.

Módulo: Casos Psicológicos

Los casos son el centro del sistema. Cada caso tiene:

  • Un estudiante asociado (id_estudiante)
  • Un psicólogo responsable (id_psicologo)
  • Una prioridad: baja, media, alta, crítica
  • Un estado: abierto, en_proceso, cerrado
  • Una categoría: Ansiedad, Conducta, Estado de ánimo, etc.

Para agregar una nueva categoría de caso:

<!-- En index.html, busca el select de categorías: -->
<select class="form-control" id="caso-categoria">
  <option value="Ansiedad">Ansiedad</option>
  <option value="Conducta">Conducta / Agresividad</option>
  <!-- AGREGA TU NUEVA CATEGORÍA AQUÍ: -->
  <option value="TDAH">TDAH / Hiperactividad</option>
</select>

Los diagnósticos incluyen integración con la Clasificación Internacional de Enfermedades CIE-10. Cada diagnóstico puede tener una sugerencia generada por IA.

El sistema de citas permite agendar sesiones presenciales o virtuales. Las citas se muestran ordenadas por fecha (más reciente primero).

Módulo: Alertas

Las alertas son el mecanismo de detección temprana del sistema. Pueden ser creadas manualmente o (en el futuro) automáticamente por la IA.

Niveles de alerta:

NivelDescripciónAcción
🔴 CríticoRiesgo inminente para el estudianteIntervención inmediata
🟡 AdvertenciaSituación que requiere seguimientoContactar en 48h
🔵 InformativoNota de seguimientoRegistrar y monitorear

Para marcar una alerta como leída, haz clic sobre ella. La burbuja roja del sidebar desaparece cuando todas están leídas.

Módulo: Inteligencia Artificial

¿Cómo funciona la IA incluida?

La IA actual es un motor de análisis local e inteligente que no necesita internet ni API keys. Funciona así:

  1. Lee los datos reales del sistema (estudiantes, casos, alertas, citas)
  2. Calcula métricas y detecta patrones (estudiantes en riesgo, carga de trabajo, etc.)
  3. Genera un informe textual personalizado basado en esos datos
  4. Guarda el informe como un reporte en la base de datos

Tipos de análisis disponibles:

AnálisisQué genera
GeneralResumen completo del sistema con KPIs y recomendaciones
Alertas activasAnálisis de todas las alertas sin atender
Casos abiertosResumen y priorización de casos activos
Estudiantes en riesgoIdentifica quién necesita atención urgente
Recomendaciones de citasSugiere a quién citar próximamente
Consulta personalizadaAnálisis general con tu pregunta específica

Opción gratuita: Google Gemini

Google Gemini tiene un plan gratuito generoso. Pasos:

1

Obtén tu API Key gratuita

Ve a aistudio.google.com → "Get API Key" → copia la clave.

2

Crea un backend Python (gratis con Render.com)

# backend.py
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
import google.generativeai as genai

genai.configure(api_key="TU_GEMINI_API_KEY_AQUI")

app = FastAPI()
app.add_middleware(CORSMiddleware, allow_origins=["*"])

@app.post("/ia/analizar")
async def analizar(datos: dict):
    model = genai.GenerativeModel('gemini-1.5-flash')
    prompt = f"""Eres un asistente psicológico educativo. 
    Datos del sistema: {datos['contexto']}
    Solicitud: {datos['pregunta']}
    Responde en español con análisis clínico apropiado."""
    
    response = model.generate_content(prompt)
    return {"respuesta": response.text}

# Para correr: uvicorn backend:app --reload
3

Modifica app.js para llamar tu backend

// Reemplaza la función generarRespuestaIA() por:
async function generarRespuestaIA(contexto, custom) {
  const response = await fetch('https://tu-backend.render.com/ia/analizar', {
    method: 'POST',
    headers: {'Content-Type': 'application/json'},
    body: JSON.stringify({
      contexto: JSON.stringify({
        estudiantes: STATE.estudiantes.length,
        casos: STATE.casos.length,
        alertas: STATE.alertas.filter(a => !a.leida).length
      }),
      pregunta: custom || `Análisis de tipo: ${contexto}`
    })
  });
  const data = await response.json();
  return data.respuesta;
}

Publicar como App Android (Play Store)

💡 ¿Qué es una PWA? Progressive Web App — tu página web se comporta como una aplicación nativa en el celular.

Método 1: PWA directa (más fácil)

Cuando publiques en Netlify o GitHub Pages, los usuarios en Android pueden "Instalar" la app desde el navegador Chrome:

  1. El usuario abre tu URL en Chrome Android
  2. Chrome muestra un banner "Instalar PsicoEscuela"
  3. Al instalar, aparece como icono en la pantalla de inicio
  4. Funciona sin barra de navegador (como app nativa)

Método 2: APK real para Play Store

# Instala Node.js (nodejs.org) y luego:
npm install -g @bubblewrap/cli

# Inicializar (necesitas la URL publicada de tu app):
bubblewrap init --manifest https://tu-app.netlify.app/manifest.json

# Construir el APK:
bubblewrap build

# El APK generado se puede subir a Play Store
